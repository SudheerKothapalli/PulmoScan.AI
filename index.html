Abstract

This project focuses on lung cancer detection using deep learning on CT scan images. Lung cancer is one of the leading causes of death worldwide, and early detection is essential to improve survival rates. The dataset consists of CT scan images categorized into four classes: Adenocarcinoma, Large Cell Carcinoma, Squamous Cell Carcinoma, and Normal. These images are preprocessed and classified using deep learning models such as ResNet-50, ResNet-101, GoogLeNet, and EfficientNet-B0. The performance of the models is evaluated using accuracy and ROC curves. Among all models, GoogLeNet achieved the best accuracy of 91.75%.

Objective

To develop an accurate deep learning-based system for detecting and classifying lung cancer using CT scan images. The system classifies images into the following categories: Adenocarcinoma, Large Cell Carcinoma, Squamous Cell Carcinoma, and Normal — enabling automated, fast, and reliable diagnosis support.

Lung Cancer Classes

A

Adenocarcinoma

Most common type. Occurs in outer/peripheral lung regions. Shows ground-glass opacity and spiculated margins.

L

Large Cell Carcinoma

Fast-growing cancer. Can occur anywhere in lungs. Large peripheral mass with necrosis/cavitation.

S

Squamous Cell Carcinoma

Develops in central airways near bronchi/hilum. Linked to smoking. Distinctive thick-walled cavitation.

N

Normal

Healthy lung tissue with no abnormalities. Clear bilateral lung fields with normal vascular markings.

Model Description

50 Layers

ResNet-50

Deep residual network using skip connections for feature extraction. Handles vanishing gradient problem. Training Acc: 91.2% · Test: 90.48%

101 Layers

ResNet-101

Deeper residual network with more layers for complex feature learning. Training Acc: 92.0% · Test: 90.16%

22 Layers · BEST MODEL ★

GoogLeNet (InceptionV3)

Uses inception modules for multi-scale feature learning. Best performing model. Training Acc: 93.5% · Test: 91.75% · Mean AUC: 0.988

237 Layers

EfficientNet-B0

Optimized model scaling width, depth, and resolution uniformly. Training Acc: 75.0% · Test: 71.75%

~23 Layers

U-Net

Encoder-decoder architecture used for segmentation of lung nodule regions from CT scan images. Produces binary lung masks.

Explainability

Grad-CAM

Gradient-weighted Class Activation Mapping. Provides visual heatmap explanation showing where the model focused for prediction.

Implementation Pipeline

1

Lung CT Image Input

CT scan images loaded from IQ-OTH/NCCD Lung Cancer Dataset (Kaggle)

2

Preprocessing

Noise removal, contrast enhancement, and resizing of CT scan images to standard dimensions

3

Data Augmentation

Rotation, horizontal flipping, and scaling applied to increase dataset diversity and prevent overfitting

4

U-Net Segmentation

U-Net model (encoder: ResNet34) segments lung nodule regions and generates binary lung masks

5

CNN Classification

ResNet-50, ResNet-101, GoogLeNet, and EfficientNet-B0 classify CT images into cancer types

6

Grad-CAM Output

Displays prediction results along with Grad-CAM heatmaps for visual explainability
