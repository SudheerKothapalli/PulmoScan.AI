# PulmoScan AI 🫁

An AI-powered lung CT scan analysis web app.

## Features
- Upload any CT scan image (PNG/JPG)
- U-Net lung segmentation
- EfficientNet-B0 cancer classification
- GradCAM heatmap visualisation
- Doctor's recommendations

## Cancer Types Detected
- Adenocarcinoma
- Large Cell Carcinoma
- Squamous Cell Carcinoma
- Normal

- PyTorch · U-Net · EfficientNet-B0 · GradCAM
- HTML / CSS / JavaScript (frontend)
- Flask (Python backend)
