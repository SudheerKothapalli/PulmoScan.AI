# 🫁 PulmoScan.AI

PulmoScan.AI is a web-based application designed to analyze **lung (chest X-ray) images** using Artificial Intelligence.  
The system allows users to upload chest X-ray images and get predictions related to lung conditions.

---

## 🚀 Features

- 📤 Upload **lung (chest X-ray) images only**
- 🤖 AI-based prediction system
- 📊 Displays prediction result clearly
- 💻 Simple and user-friendly interface
- ⚡ Fast processing of uploaded images

---

## 🧠 How It Works

1. User uploads a **chest X-ray image**
2. The image is processed by the system
3. The AI model analyzes lung patterns
4. Prediction result is displayed on screen
